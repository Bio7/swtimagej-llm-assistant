# SWTImageJ LLM Assistant

SWTImageJ plugin connecting SWTImageJ to OpenAI-compatible LLMs
(OpenAI, LM Studio, Ollama).

### Installation

Just copy SWTImageJ LLM Assistant to the plugins folder of SWTImageJ.
